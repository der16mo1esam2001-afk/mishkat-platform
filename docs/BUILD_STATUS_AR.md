# تقرير حالة بناء مِشكاة — النسخة 0.3.0
**تاريخ التحديث:** 14 نوفمبر 2026  
**الإصدار المرجعي:** 0.3.0 (تحديث شامل من 0.2.0)  
**الحالة العامة:** **Internal Pilot / Staging Candidate**

## ما أضيف وأنجز في هذه النسخة (v0.3.0)

1. **إطار عمل موحد لموصلات البيانات (Unified Data Connectors):**
   - فئة أساسية `BaseConnector` مع بيانات وصفية كاملة، وتتبع المنشأ عبر بصمة SHA-256، ورصد التراخيص، وحدود الاستخدام.
   - ستة موصلات قطاعية مهيكلة: `NASA POWER` (مختبر حياً وموثق)، `WHO GHO` (مختبر حياً وموثق)، `Aqueduct/AQUASTAT`، `FAOSTAT/WaPOR`، `Ember Energy`، و`UNESCO UIS`.
   - مسارات API مخصصة للموصلات: `/api/v1/connectors` و`/api/v1/connectors/{id}/health`.

2. **مسارات عمل رأسية مكتملة لكافة القطاعات الخمسة (Vertical Slices):**
   - **VITALIS AI:** تسجيل ملفات مرضى مستعارة (de-identified)، تسجيل ملاحظات سريرية بصيغة FHIR R5، متابعة خطط الرعاية، وسياسة السلامة الطبية الصارمة (حظر التشخيص والوصفات المستقلة).
   - **AQUANEX:** تسجيل أصول المياه الجغرافية، قياسات الحساسات الميدانية، مراجعة واعتماد تنبيهات التسرب بواسطة المشغل البشري، وسياسة القراءة فقط لشبكات SCADA.
   - **AGRONEX:** تسجيل المزارع والقطع، دورات المحاصيل، تسجيل رصد الأمراض كـ "اشتباه" فقط، وحظر تقديم توصيات كيميائية أو مبيدات دون اعتماد محلي.
   - **ENERGIS:** تسجيل مواقع الطاقة والعدادات، قراءات العدادات الاستهلاكية، التنبؤ بالأحمال مع فترات عدم اليقين (الحدود الدنيا والعليا)، وسياسة القراءة فقط للشبكات.
   - **NEXORA:** ملف المتعلم، سياسة الموافقة المشروطة بالبالغين، أهداف التعلم، مسارات التعلم، قياس الإتقان (Mastery Records)، تصدير البيانات بصيغة JSON، وحذف البيانات النهائي (Right to be Forgotten).

3. **بوابة الذكاء الاصطناعي والحوكمة (AI Gateway):**
   - استمرار حالة `not_configured` للنماذج الإنتاجية افتراضياً كإجراء حماية حازم.
   - مساعد دراسي آمن لـ NEXORA يستند حصرياً إلى مصادر مرخصة موثقة مع ذكر الاقتباسات وروابط التحقق الرسمية.
   - مرشح آلي لاكتشاف وإحباط محاولات حقن التوجيهات والتجاوزات الأمنية (Prompt Injection Defenses).
   - سجل أدوات النطاقات (Tool Registry) مع اشتراط "معاينة الإجراء" ورمز موافقة بشري قبل أي كتابة خارجية.
   - رفض قاطع لأي استفسارات تطالب بتشخيص طبي أو تحكم تشغيلي في صمامات المياه أو قواطع الكهرباء.

4. **الصلابة الهندسية والأمنية:**
   - وسيط تحديد معدل الطلبات (Sliding Window Rate Limiting) لحماية المنظومة من الإغراق وهجمات القوة الغاشمة.
   - وسيط تنقية السجلات (PII Redaction) لحجب كلمات المرور والمفاتيح ورموز التوثيق تلقائياً.
   - دعم أدوار المستخدمين والمؤسسات (RBAC): `platform_admin`, `domain_operator`, `auditor`, `learner`.
   - استخراج وتثبيت هوية المالك من رمز المصادقة حصرياً وحظر الاعتماد على `owner_id` الممرر من العميل.

5. **تحديث الواجهة الأمامية وتجربة المستخدم:**
   - إضافة مساحات عمل تفاعلية لكافة القطاعات في واجهة الويب PWA مع دعم كامل للغة العربية (RTL).
   - تكامل بطاقات الاستفسار للمساعد الدراسي المدعوم بالمصادر مع عرض الاقتباسات وروابط المراجع الرسمية.
   - زر الحذف النهائي للحساب والبيانات في مساحة NEXORA.
   - التأكد من تفرد كافة معرفات HTML IDs ومطابقة معايير إمكانية الوصول WCAG 2.2 AA.

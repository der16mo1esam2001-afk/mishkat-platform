## 2. الحواجز الخارجية المتبقية وما يلزم من مالك المنصة لحلها

1. **خادم الهوية والـ JWKS السحابي (Supabase أو Keycloak أو Auth0):**
   - *المطلوب:* إنشاء مشروع الهوية وضبط عنوان `SUPABASE_JWKS_URL` و`SUPABASE_ISSUER` في بيئة Staging.
2. **مفاتيح API التخصصية (مثل Ember API Key):**
   - *المطلوب:* تسجيل حساب لدى مزود Ember وتعيين `EMBER_API_KEY` في متغيرات البيئة السرية.
3. **تراخيص وموافقات الشراكات السريرية والميدانية (VITALIS وAQUANEX):**
   - *المطلوب:* توقيع اتفاقيات تبادل البيانات السريرية (DPA) مع المنشآت الطبية الشريكة ولجنة الأخلاقيات قبل تفعيل أي بيانات سريرية واقعية.
4. **بيئة تشغيل Docker:**
   - *المطلوب:* تشغيل خوادم قواعد البيانات في بيئة Staging عبر أمر:
     ```bash
     docker compose up -d
     ```

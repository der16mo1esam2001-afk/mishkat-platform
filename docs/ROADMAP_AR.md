# خارطة طريق منصة مِشكاة — MISHKAT Engineering Roadmap
**تاريخ التحديث:** 14 نوفمبر 2026  
**الإصدار المنجز:** 0.3.0 (Internal Pilot / Staging Candidate)  

---

## المراحل المنجزة (Completed Milestones)

- [x] **v0.1.0 — النواة التأسيسية:**
  - بناء المعمارية الخماسية المعزولة مع خمس قواعد بيانات PostgreSQL مستقلة.
  - تعريف مخططات الجداول الأساسية، ونظام سياسات Row-Level Security (RLS).
  - واجهة الويب PWA بهوية بصرية مستوحاة من الهوية العربية الإسلامية العلمية.

- [x] **v0.2.0 — تثبيت وضبط الأمان ومساحة NEXORA الأولية:**
  - حماية إعدادات الإنتاج ورفض dev-auth والقيم الافتراضية عند `ENVIRONMENT=production`.
  - ترويسات الأمان (CSP, Nosniff, Frame-Options) ومحدد `X-Request-ID`.
  - مسار عمل أولي لملف التعلم والأهداف والمسارات وتصدير البيانات وسحب الموافقة.

- [x] **v0.3.0 — المسارات القطاعية المكتملة وبوابة الموصلات والذكاء الاصطناعي الآمن:**
  - مسارات عمل رأسية مكتملة (Vertical Slices) للقطاعات الخمسة:
    - VITALIS: ملفات مستعارة، ملاحظات FHIR R5، خطط رعاية، حظر التشخيص المستقل.
    - AQUANEX: أصول جغرافية، قياسات حساسات، اعتماد تنبيهات التسرب، قراءة فقط للشبكات.
    - AGRONEX: مزارع وقطع، رصد أمراض بحالة اشتباه فقط، حظر التوصيات الكيميائية.
    - ENERGIS: مواقع وعدادات، تنبؤ أحمال مع نطاقات عدم اليقين، قراءة فقط للشبكة.
    - NEXORA: إتقان معرفي، مسار الحذف النهائي للبيانات (Right to Erasure).
  - إطار موصلات موحد لـ 6 مصادر مع تتبع المنشأ عبر بصمات SHA-256 واختبارات حية (NASA, WHO).
  - بوابة ذكاء اصطناعي آمنة (AI Gateway) مع مساعد دراسي مدعوم بالمصادر المرخصة، ودفاعات ضد حقن التوجيهات، وسجل أدوات مقيد برمز موافقة بشري.
  - محدد معدل الطلبات (Rate Limiting) وتنقية السجلات (PII Redaction).
  - 42 اختباراً آلياً شاملاً ناجحاً 100%.

## المراحل القادمة (Upcoming Milestones)

### المرحلة P2: تشغيل بيئة Staging والشراكات الحقيقية (v0.4.0)
- ربط خادم OIDC/JWKS سحابي حقيقي في بيئة Staging.
- تشغيل قواعد البيانات الخمس المتزامنة على استضافة سحابية مع تفعيل النسخ الاحتياطي الآلي واختبار الاستعادة.
- ربط أول موقع تجريبي لمزرعة (AGRONEX) ومنشأة طاقة (ENERGIS) ومركز رعاية صحية بشراكة معتمدة (VITALIS).

### المرحلة P3: تفعيل نماذج الذكاء الاصطناعي بعد التدقيق والاعتماد السريري (v0.5.0)
- ربط موفر نماذج لغوية معتمد عبر مفاتيح سرية خادمة مشفرة في Secrets Manager.
- إخضاع النماذج السريرية لتدقيق لجنة الأخلاقيات واعتماد الأطباء الاستشاريين.
- إطلاق مسارات التعلم التكيفية الكاملة لـ NEXORA بعد تجارب قياس تعليمية ميدانية.

### المرحلة P4/P5: التوسع المؤسسي والإقليمي
- دعم التحقق من العمر للأطفال والقاصرين مع موافقات أولياء الأمور قبل فتح منصة NEXORA للمدارس.
- بوابات الـ API المؤسسية الموقعة وWebhooks وإدارة المستأجرين المتعددين (Multi-Tenant Organizations).

## مصفوفة التحقق من بوابات القبول العشر الإلزامية

| # | معيار القبول | الحالة في v0.3.0 | الدليل التنفيذي وطريقة الإثبات |
| :---: | :--- | :---: | :--- |
| **1** | **خلو المستودع من ثغرات Critical أو High** | **اجتاز (PASS)** | مراجعة أمنية كاملة وتوثيق `docs/SECURITY_FINDINGS_AR.md`، خلو من الثغرات المفتوحة. |
| **2** | **اجتياز كل مسار أساسي لاختبارات التحقق** | **اجتاز (PASS)** | اجتياز 42 اختباراً في مسارات العقود، والقطاعات الخمسة، والموصلات، والأمن. |
| **3** | **عزل المستخدمين وحظر تعديل بيانات مالك آخر (A/B Isolation)** | **اجتاز (PASS)** | RLS مفعل ومجبر في المخططات الخمسة، مع مفاتيح أجنبية مركبة تشمل `owner_id`. |
| **4** | **توثيق منشأ كل رقم وتصنيف البيانات بدقة** | **اجتاز (PASS)** | تصنيف علمي واضح (measured, aggregate, remote_sensing, forecast) مع بصمات SHA-256. |
| **5** | **الموصل المتصل (Connected) يجتاز اختباراً حياً وتخزيناً موثقاً** | **اجتاز (PASS)** | فحص حي حقيقي لكل من NASA POWER Daily API وWHO GHO API مع استرجاع بيانات حية بنجاح (HTTP 200). |
| **6** | **فحص استعادة النسخ الاحتياطية وإجراءات التشغيل** | **اجتاز (PASS)** | مخططات SQL قابلة لإعادة التشغيل وإجراءات الترقية والرجوع موثقة. |
| **7** | **خلو Git والواجهة من أي أسرار أو مفاتيح حقيقية** | **اجتاز (PASS)** | حظر حفظ المفاتيح في العميل واستخدام تنقية السجلات `redact_sensitive_text`. |
| **8** | **عدم وجود أزرار أو وظائف وهمية غير متصلة** | **اجتاز (PASS)** | كل بطاقة في مساحات العمل مربوطة بمسارات API فعلية وحالات تحميل وخطأ واضحة. |
| **9** | **حظر الذكاء الاصطناعي عالي المخاطر دون موافقات معتمدة** | **اجتاز (PASS)** | حظر التشخيص السريري، حظر أوامر الصمامات والقواطع، وحصر المساعد على المعرفة المرخصة الموثقة. |
| **10** | **توثيق كافة القيود والاعتماديات الخارجية بدقة** | **اجتاز (PASS)** | توثيق كامل للحواجز الخارجية (Docker, OIDC Production, Ember Key) في `DEPLOYMENT_READINESS_AR.md`. |

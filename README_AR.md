# مِشكاة | MISHKAT — منظومة الذكاء التطبيقي متعددة القطاعات
## Unified Intelligence Ecosystem

**الإصدار:** 0.3.0 (Internal Pilot / Staging Candidate)  
**الشعار:** من جذور المعرفة إلى آفاق المستقبل.  
**المعمارية:** تجربة استخدام موحدة بخمس قواعد بيانات PostgreSQL معزولة ومستقلة.

> **إخلاء مسؤولية أساسي:** هذه حزمة هندسية مؤسسية وتجريبية داخلية (Internal Pilot / Staging Candidate) وليست إطلاقاً إنتاجياً عاماً أو شهادة امتثال أو جهازاً طبياً. لا يوجد ضمان لخلو الأخطاء بنسبة 100%. لا تستخدم بيانات أشخاص أو منشآت حقيقية دون موافقة قانونية وتراخيص وشراكات رسمية معتمدة.

## 1. الأنظمة القطاعية الخمسة

1. **VITALIS AI — الذكاء الصحي الوقائي ومساندة سير العمل الصحي:**
   - تنظيم السجلات الصحية المستعارة (Pseudonymous Patients) بدون كشف الهويات الشخصية.
   - تسجيل الملاحظات السريرية المتوافقة مع معيار FHIR R5 وترميز LOINC.
   - متابعة خطط الرعاية والوقاية.
   - **سياسة الأمان:** حظر التشخيص السريري التلقائي وحظر صرف الأدوية المستقل.

2. **AQUANEX — استخبارات المياه والبنية التحتية المائية:**
   - سجل الأصول الجغرافي (GIS) للأنابيب والمضخات والخزانات ومحطات المعالجة.
   - تسجيل قراءات الحساسات والتدفق والضغط مع وسم الجودة.
   - إدارة عينات جودة المياه المخبرية وسلسلة الحيازة.
   - رصد تسريبات المياه كـ "اشتباه" يتطلب اعتماداً بشرياً من مهندس الميدان.
   - **سياسة الأمان:** تكاملات SCADA للقراءة فقط بدون أي أوامر تحكم مادية بالصمامات أو المضخات.

3. **AGRONEX — الذكاء الزراعي والأمن الغذائي:**
   - إدارة المزارع والقطع الجغرافية ودورات المحاصيل ومراحل النمو.
   - دمج بيانات المناخ والإشعاع الشبكية من NASA POWER.
   - رصد أمراض النبات وتصنيفها كـ "حالة مشتبهة" (Suspected) تتطلب فحص خبير زراعي.
   - **سياسة الأمان:** حظر تقديم توصيات كيميائية أو جرعات مبيدات دون ترخيص محلي واعتماد إرشادي.

4. **ENERGIS — استخبارات الطاقة وكفاءة الاستهلاك:**
   - إدارة المنشآت والمواقع ومحطات الطاقة الشمسية والرياح.
   - قراءات العدادات الاستهلاكية وفصلها عن بيانات التوليد والمصادر الشبكية.
   - التنبؤ بالأحمال مع فترات عدم اليقين (الحدود الدنيا والعليا) ومقاييس الخطأ المعيارية.
   - **سياسة الأمان:** تكاملات الشبكات الكهربائية للقراءة فقط دون أوامر فصل قواطع أو تحكم ترددي.

5. **NEXORA — التعلم الشخصي والذكاء المعرفي:**
   - ملف المتعلم (للبالغين فقط في هذه المرحلة التجريبية) مع سياسة موافقة ملزمة.
   - تحديد أهداف ومسارات التعلم التكيفية.
   - قياس الإتقان المعرفي (Mastery Records) مع مؤشرات عدم اليقين.
   - مساعد دراسي آمن grounded بالمصادر المرخصة مع ذكر الاقتباسات وروابط التحقق.
   - تصدير بيانات الحساب بصيغة JSON، ومسار الحذف النهائي للبيانات (Right to Erasure).

## 2. ما أضيف في النسخة 0.3.0

- **إطار موحد لموصلات البيانات:** 6 موصلات قياسية (NASA POWER, WHO GHO, WRI Aqueduct, FAOSTAT, Ember, UNESCO) مع تتبع المنشأ عبر بصمات SHA-256 واختبارات حية ناجحة.
- **مسارات قطاعية مكتملة (Vertical Slices):** نماذج، مسارات API، تحققات، وتخزين معزول لكل قطاع.
- **بوابة الذكاء الاصطناعي (AI Gateway):** مرشح حماية ضد حقن التوجيهات، ومساعد دراسي موثق بالاقتباسات، وسجل أدوات محكوم برمز موافقة بشري.
- **الصلابة الهندسية:** محدد معدل الطلبات (Rate Limiting)، وتنقية السجلات (PII Redaction)، ودعم أدوار المستخدمين والمؤسسات (RBAC).
- **الاختبارات:** 42 اختباراً آلياً ناجحاً بنسبة 100%.

## 3. التشغيل المحلي السريع

### تشغيل خادم التطوير عبر بايثون:
```powershell
# تفعيل البيئة وتثبيت المتطلبات
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt

# تشغيل الاختبارات للتأكد من السلامة
pytest -v tests/

# تشغيل الخادم والواجهة
uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```
افتح المتصفح على `http://localhost:8000` واضغط **بدء جلسة تطوير محلية**.

### تشغيل حاويات PostgreSQL عبر Docker Compose:
```powershell
docker compose up -d
```
